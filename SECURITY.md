# Security

BUIA is a single-user tool for your own PC and your own tailnet. It is not built for the open internet (see README > Security).

Only the latest release gets fixes.

To report a vulnerability, use GitHub's private reporting (the repository's Security tab, "Report a vulnerability"), or write to contaldicarlo@gmail.com. Please do not open a public issue for it. This is a one-person project, so replies are best effort.
